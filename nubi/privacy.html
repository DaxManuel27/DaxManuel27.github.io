Nubi privacy policy

Last updated: November 17, 2026. Policy version: 1. Applies to Nubi 1.0.0 with billing disabled.

Publisher: Dax Manuel

Contact: mail@daxmanuel.com

What Nubi does

Nubi is an independent academic planner for UNB Brightspace. It is not affiliated with or endorsed by the University of New Brunswick or D2L.

Before accessing coursework, Nubi asks you to connect Brightspace. It uses the session already signed in at lms.unb.ca. You sign in with UNB directly. Nubi does not ask for your password or read authentication cookie values. You can instead choose sample data, which shows made-up courses and deadlines and reads nothing from Brightspace.

Information processed

Nubi processes Brightspace responses to identify your account and accessible enrollments, then selects confirmed current-semester courses for coursework collection. It saves your account identifier, name, initials, selected course identifiers/names, dated coursework, completion status, and source links. This supports the deadline list, account separation, refreshes, and reminders. API responses may contain additional fields or older records; the planner keeps the fields needed for its features. Unconfirmed-term courses and unsupported sources may be absent.

Calendar imports process the ICS file you choose, including event identifiers, titles, times, recurrence definitions, rooms, descriptions, timezone definitions, and filename. Imported attachments and alarms are not used; remote calendar files and attachments are not fetched. Personal events store the titles, dates, descriptions, locations and colors you enter.

Preferences, consent version/time, reminder delivery state, and recent sync status are saved. A bounded diagnostic report retains aggregate counts, request status codes and timings; saved reports exclude course names, student IDs, response samples, request paths and free-form errors.

Storage, use, and transmission

Planner data and settings are stored in this Chrome profile on this computer using chrome.storage.local. Temporary interface and reminder-navigation state also uses chrome.storage.session, which Chrome clears when the browser session ends. The extension does not use chrome.storage.sync. Calendars are separated by Brightspace account. Background refreshes make authenticated HTTPS requests only to lms.unb.ca, normally about every 30 minutes while Chrome runs. Opening a source link opens Brightspace in Chrome. UNB/D2L handle their own service's requests under their applicable policies.

This billing-disabled build does not send planner data to the publisher or a third-party backend. It has no advertising, sale of data, or usage analytics. It does not scan unrelated browsing history. Its page bridge is restricted to the UNB Brightspace origin and allowlisted read-only API routes. Local check-offs and calendar edits do not change your Brightspace coursework or submit work.

Notifications are passed to Chrome and the operating system and can show course/item details on a lock screen. Delivery depends on Chrome running, a valid session, network and operating-system settings; it is not guaranteed at an exact time.

Why Chrome asks for these permissions

Storage (storage)

Saves your coursework cache, imported calendars, personal events, preferences, consent, diagnostics and reminder state in this Chrome profile. It also holds temporary interface state for the current browser session. It does not upload these records to Chrome account sync.

Notifications (notifications)

Shows desktop reminders for coursework deadlines, changed due dates and personal events. Reminder text can include course or event details. You can adjust coursework reminders and muted courses in Settings, control personal-event reminders in Calendar, or turn off Chrome notifications in your operating system.

Alarms (alarms)

Lets Chrome wake the extension to refresh coursework and check or deliver scheduled reminders while Chrome is running, even when the side panel is closed. These are background timers, not access to your device's alarm-clock app. Sleep and browser shutdown can delay them.

Side panel (sidePanel)

Displays your deadlines, class calendar and settings beside the web page you are viewing when you open Nubi from Chrome's toolbar. This permission provides the panel; it does not give the extension access to every page you browse.

UNB Brightspace access (https://lms.unb.ca/*)

Allows the extension to read supported Brightspace information using your existing signed-in session after you choose Connect Brightspace. A small script on lms.unb.ca can relay the same permitted read-only requests through an open Brightspace tab. The extension does not ask for your UNB password, read cookie values, edit the Brightspace page, or request access to other websites in this build.

Retention and your choices

Local cached coursework is updated as refreshes succeed. The planner displays confirmed current-term courses and dated work from the current semester onward. Some recovery data can remain until a successful refresh. Imported definitions, past personal events, inactive-account calendars and settings persist until removed or all data is deleted. The most recent diagnostic report replaces its predecessor.

In Settings, Delete my data removes saved coursework, imports, personal events, diagnostics and consent from this installation, resets preferences to their defaults, and stops scheduled planner processing. A new explicit connection is required to read Brightspace again. Deletion does not change Brightspace records or delete files you downloaded or messages you sent to support. Uninstalling removes this extension's local Chrome storage. There is no automatic cross-device backup or sync.

Encrypted backup export is optional and initiated by you. It saves this account's imported calendars, personal events and recurrence exceptions, calendar preferences, event reminders, coursework reminder settings, muted courses and local deadline check-offs to a file encrypted with your passphrase. The passphrase is not stored and cannot be recovered. It does not export consent, authentication credentials or raw coursework responses. Restoring replaces this account's calendars, matching local check-offs and the profile's coursework reminder preferences after confirmation. Older calendar-only backups leave coursework preferences and check-offs unchanged. A local recovery journal may temporarily retain the validated restore data until an interrupted restore finishes; deleting local data clears it. Keep your downloaded files and passphrase safe, and delete them yourself when no longer needed.

Billing in this release

Billing is disabled in this release. No billing-provider requests, subscription charges, separate billing sign-in, or Google Calendar sync are active. The repository includes a separate optional subscription integration, but this policy describes the billing-disabled extension. A subscription-enabled release needs updated disclosures identifying the providers, information shared and retention practices, along with a separate billing consent choice, before activation.

Security

UNB requests use HTTPS. Stored extension data is restricted to trusted extension contexts. These controls are not a claim that local chrome.storage.local data is application-encrypted. Your browser profile and device access controls matter. The encrypted backup feature protects exported files separately; it does not encrypt the extension's working local store.

Support and sharing

Nothing is automatically sent to the developer for support. You can inspect a diagnostic report before explicitly copying it. If you choose to contact support, send only information needed for your request and remove private coursework or identifiers. Support-message retention: support emails are kept for up to 12 months after your request is resolved, then deleted.

If you email support, the publisher and the email providers used to deliver the message process your email address, message and any attachments to respond to your request. Do not send passwords, session cookies or private coursework. Contact the public support address above for privacy questions or to request deletion of support correspondence, subject to the stated retention policy.

Visiting the public website

The privacy and support website contains static pages with no analytics scripts, tracking pixels, embedded third-party content, or contact form. Visiting the website does not give it access to your extension's stored coursework. Email links open your chosen mail application.

When this site is hosted on GitHub Pages, GitHub logs visitors' IP addresses for security purposes. This hosting activity is separate from the extension's local planner storage. See GitHub Pages data collection and the GitHub Privacy Statement.

Limited Use and changes

Nubi's use of user data adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only for the disclosed academic planning features and their necessary operation. It is not used for personalized advertising, data brokerage, credit assessment, or unrelated profiling.

Material changes to data practices will be disclosed and, where appropriate, require renewed consent before the new processing begins. The last-updated date and policy version identify this notice.
